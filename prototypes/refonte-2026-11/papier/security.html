Leon sees exactly what you are allowed to see.

Search, chat and your own AI assistant all run with the permissions of the person asking.

Two rules cover everything Leon stores.

Every item is one or the other. Email, Google Drive and Slack stay private to whoever connects them.

Shared with the team

Everything a shared connection brings in.

  • Tickets and docs
  • Meeting transcripts and CRM notes
  • Support conversations and shared inboxes

On each source: Shared with the team

Private to you

No one else sees it, in search results or in answers.

  • Your email, Google Drive and Slack
  • Your AI conversations and coding sessions
  • Your chats with Leon and the notes you save

On each source: Private to you

What is in place today.

Each point describes code that is live in the product.

  • Each company’s data isolated with row-level security

    Enforced by Postgres itself, in a single database, and covered by automated tests.

  • Credentials encrypted with AES-256-GCM

    API keys and OAuth tokens, each bound to its database row.

  • Permissions checked before anything is ranked

    In search, in chat and for your own assistant. Every source an assistant opens in full is logged.

  • Secrets masked before storage

    Key prefixes, private keys, authorization headers, .env lines. A secret in plain prose can still slip through.

  • A browser extension that asks first

    Consent, a switch per site, a pause button. No attachments, nothing in private windows.

What is in progress.

We would rather you read it here than discover it later.

  • SOC 2 and ISO 27001

    Leon holds neither certification today.

  • Mirroring each tool’s own permissions

    For now a connection’s content is shared with the whole team, except email, Google Drive and Slack.

  • Data export

    No export of a workspace’s data yet.
